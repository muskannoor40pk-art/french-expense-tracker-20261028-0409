## Overview
The Expense Tracker (French edition) is a lightweight, single-page application designed for users in West & Central Africa and Europe who need a fast, offline-first solution to monitor their spending. By utilizing `localStorage`, your financial data remains entirely on your device, ensuring complete privacy and zero server dependencies.

## Features
*   **Categorized Expenses:** Organize your spending (Food, Transport, Housing, etc.) for better clarity.
*   **Monthly Summary Cards:** Visualize your total spending at a glance with dynamic monthly cards.
*   **Native Data Visualization:** A clean, custom-built bar chart using pure CSS and JavaScript—no heavy libraries required.
*   **Persistence:** All data is saved locally in your browser; refresh or close the tab without losing your progress.
*   **Responsive Design:** Optimized for both mobile devices and desktops, using modern CSS Grid and Flexbox.

## Localization Notes
*   **Language:** The interface is fully localized in French to cater to Francophone markets in Africa and Europe.
*   **Formats:** Uses standard French number formatting (e.g., `1 250,00 €` or `FCFA`) to ensure readability for the target audience.
*   **Directionality:** Optimized for LTR (Left-to-Right) layouts.

## Tech Stack
*   **HTML5:** Semantic structure for accessibility.
*   **CSS3:** Modern layout techniques (Grid/Flexbox) and custom visual components.
*   **Vanilla JavaScript:** Lightweight logic for data processing and chart generation.
*   **Storage:** Browser `localStorage` for zero-setup data persistence.
